  MCA MINI PROJECT | INTRODUCTION
  Problem Statement & Objectives
  Department of Computer Applications | MACE
  Mar Athanasius College of Engineering, Kothamangalam
  Slide 2 of 20
  !
  Problem
  Clinical transcription data is unstructured and can belong to any of several medical specialties, making manual categorization by medical coders slow, inconsistent, and prone to human error as patient volumes grow.
  →
  Objective
  Develop an automated NLP and Ensemble Machine Learning system that predicts the correct medical specialty from a clinical transcription, reducing administrative overhead and speeding up document routing.
  Key Project Objectives
  EDA
  Explore & Analyze
  Conduct EDA on the Kaggle MTSamples clinical transcription dataset.
  NLP
  Preprocess Text
  Clean, tokenize, remove stop-words and lemmatize clinical narratives.
  TF
  Extract Features
  Vectorize clinical text into numeric form using TF-IDF.
  ⊕
  Ensemble & Deploy
  Combine SVM, RF, LR, MNB via Voting; deploy on a Flask web app.

  RELEVANCE TO THIS PROJECT

  Paper 2 • 2023
  Zhang et al. — Hindawi CIN
  METHOD
  SemiADA synthetic data augmentation + BERT, on an 18-class MTSamples subset
  KEY FINDING
  Achieved a +14.9% average gain in accuracy and F1-score over baseline, but needs GPU-heavy BERT fine-tuning.
  RELEVANCE TO THIS PROJECT
  Highlights class imbalance in MTSamples and motivates a lightweight TF-IDF + ensemble alternative.
  Paper 3 • 2022
  Blanchard et al. — IEEE JBHI
  METHOD
  CNN with keyword-constrained loss on the NCI SEER pathology registry
  KEY FINDING
  Keyword injection improved macro F1 and recall on rare classes without hurting majority performance.
  RELEVANCE TO THIS PROJECT
  Justifies using TF-IDF keyword / n-gram weighting to preserve signal for rare specialty classes.

=== SLIDE 11 ===
  MCA MINI PROJECT | DATA PREPROCESSING
  Feature Extraction Using TF-IDF
  Department of Computer Applications | MACE
  Mar Athanasius College of Engineering, Kothamangalam
  Slide 11 of 20
  TF-IDF (Term Frequency – Inverse Document Frequency) converts preprocessed clinical text into high-dimensional numeric feature vectors that machine learning classifiers can use.
  Term Frequency
  TF(t,d) = 1 + log( fₜ,d )
  Inverse Document Frequency
  IDF(t,D) = log( (1+|D|) / (1+df(t)) ) + 1
  TF-IDF Weight
  TF-IDF(t,d,D) = TF(t,d) × IDF(t,D)
  Vectorization Flow
  Clinical
  Text
  Text
  Preprocessing
  TF-IDF
  Vectorizer
  Sparse Feature
  Matrix (L2-norm)
  ⚠  TF-IDF is a feature extraction / vectorization technique — it is NOT a classification algorithm. It transforms text into numeric vectors; SVM, Random Forest, Logistic Regression and Multinomial Naive Bayes are the classifiers that use these vectors to predict a specialty. The vectorizer also extracts unigrams and bigrams (e.g. “coronary artery”) and applies sublinear TF scaling with Euclidean L2 normalization.

=== SLIDE 13 ===
  MCA MINI PROJECT | PROPOSED ALGORITHMS
  Proposed Machine Learning Algorithms
  Department of Computer Applications | MACE
  Mar Athanasius College of Engineering, Kothamangalam
  Slide 13 of 20
  SVM
  Support Vector Machine
  Finds the maximum-margin hyperplane; excels on sparse, high-dimensional TF-IDF vectors with natural linear separability.
  RF
  Random Forest
  Aggregates many decision trees via bagging; captures non-linear keyword interactions other models may miss.
  LR
  Logistic Regression
  Multinomial Softmax baseline; highly interpretable odds ratios for clinical term importance.
  MNB
  Multinomial Naive Bayes
  Probabilistic, count-based model; computationally efficient and reliable even on smaller class subsets.
  FEATURE EXTRACTION
  TF-IDF
  CLASSIFICATION
  SVM + Random Forest + Logistic Regression + Multinomial NB
  ENSEMBLE
  Voting Classifier (Soft Voting)
  ℹ  Soft voting requires calibrated probability estimates from every base classifier. Standard Linear SVM outputs uncalibrated decision-margin distances, so its scores are planned to be calibrated (e.g. via CalibratedClassifierCV / Platt scaling) before joining the soft-voting aggregation.

  Step-by-Step Algorithm Working
  Department of Computer Applications | MACE
  Mar Athanasius College of Engineering, Kothamangalam
  Slide 15 of 20

  Load the clinical transcription dataset (4,999 records).
  2
  Clean the data — remove missing transcriptions and verify no duplicates.
  3
  Split the dataset using stratified 80:20 train-test partitioning.

  Apply text preprocessing: lowercase, clean, tokenize, remove stop-words, lemmatize.

  Fit the TF-IDF vectorizer using the training partition only.
