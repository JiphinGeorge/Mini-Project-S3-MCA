# Medical Specialty Classification using TF-IDF and Ensemble Machine Learning

This repository contains the LaTeX source code for the MCA Mini Project Proposal Report.

## Compilation Instructions
To compile the document into a PDF, run the following commands in your terminal:
```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Structure
- `main.tex`: The main LaTeX file tying the document together.
- `chapters/`: Contains all individual chapters and sections.
- `references.bib`: Bibliography database using IEEE format.
