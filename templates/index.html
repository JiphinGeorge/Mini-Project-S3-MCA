System Architecture

How It Works: End-to-End Clinical NLP Pipeline

An architectural, step-by-step mathematical breakdown of how transcription parsing, TF-IDF vectorization, ensemble classification, and open-set rejection operate.

PHASE 01: DOCUMENT INGESTION PyMuPDF / Text

Document Parsing & Ingestion

Patient clinical documentation is accepted either via manual transcription entry or multi-page PDF document upload. The PDF engine utilizes in-memory byte stream extraction via PyMuPDF (fitz) to retrieve pure UTF-8 clinical text while omitting document headers and layout noise.

import fitz
doc = fitz.open(stream=pdf_bytes, filetype="pdf")
extracted_text = "\n".join([page.get_text() for page in doc])
Why this matters in clinical NLP
Clinical reports frequently contain unstructured typographical artifacts. In-memory stream extraction preserves critical syntactic proximity between symptoms and diagnoses.
PHASE 02: NLP PURIFICATION Regex & Stopwords

Text Cleaning & Tokenization

Unstructured medical dictations undergo lowercasing, non-alphanumeric noise elimination, and whitespace normalization. Punctuation characters are converted to token delimiters while preserving hyphenated anatomical descriptors. English stop words are filtered out.

cleaned = re.sub(r'[^a-zA-Z0-9\s]', ' ', raw_text.lower())
tokens = re.findall(r'\b[a-zA-Z]{2,}\b', cleaned)
filtered = [t for t in tokens if t not in STOP_WORDS]
Why this matters in clinical NLP
Standard conversational filler words like "the", "with", "from" dilute specialized clinical vocabulary. Removing them forces TF-IDF attention onto clinical tokens.
PHASE 03: TF-IDF VECTORIZATION 8,000 Dimensions

Sublinear TF-IDF Vectorization

The cleaned text is converted into an 8,000-dimensional sparse feature vector using unigrams and bigrams. Sublinear term frequency scaling replaces raw term count $TF$ with $1 + \ln(TF)$ to dampen the impact of repeated clinical tokens.

tfidf = TfidfVectorizer(max_features=8000, ngram_range=(1, 2),
                    sublinear_tf=True, min_df=2, max_df=0.70)
Why this matters in clinical NLP
A clinician repeating "coronary" ten times does not mean the document is ten times more cardiovascular than a record mentioning it twice. Logarithmic scaling prevents high-frequency term dominance.
PHASE 04: QUAD-MODEL INFERENCE SVM, LR, RF, MNB

Multi-Classifier Parallel Inference

The 8,000-dimensional vector is processed concurrently by four diverse machine learning architectures: Linear SVM (hyperplane margins), Logistic Regression (calibrated log-odds), Random Forest (decision tree bagging), and Multinomial Naive Bayes (conditional probabilities).

probs_svm = svm_model.predict_proba(vec)
probs_lr  = lr_model.predict_proba(vec)
probs_rf  = rf_model.predict_proba(vec)
probs_mnb = mnb_model.predict_proba(vec)
Why this matters in clinical NLP
Different models exhibit orthogonal inductive biases. Linear SVM discovers crisp discriminative boundaries, while Logistic Regression ensures proper probability calibration.
